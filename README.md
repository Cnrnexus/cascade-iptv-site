# Cascade IPTV site

Static pages for Cascade IPTV (privacy policy, support, sample playlist), served by GitHub Pages.
Published by CNR Nexus Consulting Inc.

Sample streams are freely licensed works (Blender Foundation open movies, CC BY) and public player test streams. Regenerate the playlist, logos and guide with `python3 tools/gen_sample.py` (the guide covers 60 days).
